CLI Reference

Command-Line Interface

Pontis provides a powerful terminal utility for credential management, agent installation, and interactive launches.

Command Description Example
pontis Interactive wizard with 1-Click Fast Launch and keyboard navigation (Tab/↑↓) pontis
pontis claude Start proxy and launch Claude Code with auto-approved keys in ~/.claude.json pontis claude
pontis codex Start proxy and launch Codex CLI via Responses API translation pontis codex
pontis hermes Start proxy and launch Hermes Agent with OpenAI compatibility endpoints pontis hermes
pontis opencode Start proxy and launch OpenCode agent bridged to selected models pontis opencode
pontis auth set <provider> Save encrypted credentials into AES-256-GCM vault (google, opencode, cloudflare) pontis auth set google
pontis models -p <provider> List and interactively pick available models for any provider pontis models -p google
pontis clients View installed agent CLIs, versions, and install missing tools pontis install claude
